# Tiny Shopping Assistant - Smart Shop Assistant

An intelligent AI-powered shopping assistant that helps users find product prices and information instantly.
Build: agent = LLM + tool + loop, Groq and Gradio
The model thinks "do I need a tool here?" → if yes, calls it → reads the result → answers. Nobody hard-codes when. That decision is the entire difference between a chatbot and an agent.

> **Live Demo: ** : https://tiny-shopping-assistant.onrender.com/

### Features

- Conversational AI for Shopping queries
- Ultra-fast responses using Groq model
- Clean UI with Gradio Soft Theme
- Deployed as a public web app
- Secure API Key management with '.eve'

### Tech Stack

- **Frontend:** Gradio
- **Backend:** Python
- **LLM:** Groq API
- **Deployment:** Render
